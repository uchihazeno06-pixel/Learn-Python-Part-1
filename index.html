📖 Python Cheat Sheet

1. Conditional Statements

If: Runs code only if a condition is True.

if x > 0: print("Positive")

If-Else: Provides a "Plan B" if the condition is False.

if x % 2 == 0: print("Even") else: print("Odd")

If-Elif-Else: Checks multiple conditions in order.

if score >= 90: print("A") elif score >= 80: print("B") else: print("F")

2. Logical Operators

and: True only if BOTH are True.
or: True if AT LEAST ONE is True.
not: Reverses the boolean.

if age >= 18 and has_id: print("Allowed")

3. For Loops

Iterates over a sequence (lists, strings, ranges).

for fruit in ["apple", "banana"]: print(fruit)

range(): Generates numbers. range(5) gives 0-4. range(1, 5) gives 1-4.

for i in range(5): print(i)

4. While Loops

Repeats as long as a condition remains True.

count = 3 while count > 0: print(count) count -= 1

5. Loop Control

break: Exits the loop entirely.
continue: Skips the current iteration.
pass: Does nothing.

for i in range(5): if i == 3: break # Stops the loop

6. Functions

Reusable blocks of code. Defined with def.

def greet(): print("Hello!") greet() # Calls the function

Parameters & Arguments: Pass data into functions.

def my_sum(a, b): return a + b result = my_sum(3, 5)

Return: Sends data back from the function.

def square(x): return x * x
